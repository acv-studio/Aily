# Aily

以「长期陪伴、共同经历、关系成长」为核心的 AI 亲密关系应用原型。

## 当前原型

- 三位差异化 AI 角色与主角色切换
- 液态玻璃风格的移动端消息首页
- 按角色隔离的文字聊天、DeepSeek 流式回复、停止/重试、引用、撤回和搜索
- 用户确认的分类长期记忆：来源、修订、暂停引用、删除、按角色清除和相关性检索
- 图片默认本机保存；本次显式授权后可请求已配置的视觉模型，历史图片不自动上传
- 浏览器语音听写填入草稿、手动朗读角色文字；保留本机录音/回放
- 前台本地定时问候/跟进、免打扰和可选系统通知（不是后台推送）
- AI 角色动态、关系回忆时间轴和隐私提示
- 本地优先存储，刷新后保留体验进度

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 聊天与记忆

在“我的 → DeepSeek 连接”填写自己的 API Key。对话及少量相关确认记忆会直发配置的服务；Key 只保存在当前浏览器会话。没有 Key 时明确使用本地演示回复，不是 AI 生成内容。不要在客户端构建中预置生产密钥。

用户消息在请求前写入 IndexedDB。回复失败或停止后可重试，刷新不丢失已保存消息。图片（3MB 内）默认本机保存；勾选本次识图授权才发送当前图片和最多1000字描述，重试会重新询问授权，历史图片不会随文字轮次上传。必须在设置中填写有效 Key 和支持图像输入的模型/接口；无 Key 不伪造识图结果。DeepSeek 当前官方文档的 `deepseek-flash` 提供图像输入，实际账号支持须真实测试，不自动改动你的文字模型配置。

语音录音（最长60秒、3MB内）仍只在本机保存；独立听写功能使用浏览器 SpeechRecognition，不会转录旧录音文件。音频可能发给浏览器厂商，需单独授权；确认的文字进入草稿，用户检查后手动发送。朗读使用浏览器语音合成，不是角色原声，也不会自动播放。支持程度、语音服务、权限及 HTTPS 因浏览器而异。

“我的”中的本地主动提醒默认关闭，按设备本地时间每天每角色最多一次，只作用于当前选择角色；免打扰/聊天忙碌时跳过，错过分钟不补发。内容明确为本地固定文案，不调用付费模型；系统通知需主动申请权限且不展示聊天细节。应用关闭后不通知，浏览器节流/休眠可能漏发；跨标签页 Web Locks 可用时串行，缺失时防重复是尽力而为。失败消耗当日名额避免重试轰炸。提醒设置/去重记录保存在浏览器，不跨设备同步、不包含聊天内容或Key。

**仍未完成：真实语音／视频通话、角色原声、关闭应用后的通知和有效 Key 的实际服务验证。** 当前原型不以听写+朗读或摄像头预览冒充通话，需提供专用服务接口/测试凭据和后台平台支持后才能接入。

在聊天消息下选择“记住这条”，先编辑内容及分类，再确认保存。回忆页支持按角色/分类筛选、检索、修订、暂停引用和删除。撤回原消息不自动删除已单独确认的记忆；需要时请在回忆页删除。已经发送给外部服务的上下文无法撤回。

本地召回最多 5 条相关记忆、共 2000 字，近期上下文最多 12 条/6000 字，另附少量确定性历史摘录；不是自动生成的全历史摘要或向量语义检索。不要把未确认的模型推断当作长期记忆。

本机数据支持密码加密导出/导入。导入替换现有数据并在写入前进行校验；忘记密码无法恢复。清除站点数据或卸载浏览器仍可能丢失未备份记录。

## 验证

```bash
npm run build
npx vitest run --pool=threads
# 在 npm run dev 启动后：
node scripts/verify-chat-memory.mjs
```

浏览器脚本在隔离上下文中验证发送、确认记忆、纠错、刷新、暂停引用、搜索、角色隔离和删除，不修改你的现有浏览器数据。真实 DeepSeek 服务需自带有效 Key；自动化测试使用模拟响应，不产生真实 API 费用。
