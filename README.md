# Aily

以「长期陪伴、共同经历、关系成长」为核心的 AI 亲密关系应用原型。

## 当前原型

- 三位差异化 AI 角色与主角色切换
- 液态玻璃风格的移动端消息首页
- 按角色隔离的文字聊天、DeepSeek 流式回复、停止/重试、引用、撤回和搜索
- 自动提议、用户确认的分类长期记忆：原话/来源、重要度、固定、情境到期、归档、冲突确认和纠错
- 持续更新的日/周/月/年本地话题摘要与中英文主题语义检索（未知主题使用文字匹配）
- 按角色关闭记忆类别/智能整理，以及不落盘、不读取长期记忆的临时会话
- 图片分享与语音录制/回放（仅本机保存，不提供模型视觉理解或语音听写）
- AI 角色动态、关系回忆时间轴和隐私提示
- 本地优先存储，刷新后保留体验进度
- 完整中英文界面、独立聊天语言设置及跨语言原文记忆召回；语言偏好刷新后保留

中英文语言资源、内容保留边界、验证和前后视觉对比见 [本地化说明](docs/i18n.md)。

## 聊天与记忆

在“我的 → DeepSeek 连接”填写自己的 API Key。对话及少量相关确认记忆会直发配置的服务；Key 只保存在当前浏览器会话。没有 Key 时明确使用本地演示回复，不是 AI 生成内容。不要在客户端构建中预置生产密钥。

用户消息在请求前写入 IndexedDB。回复失败或停止后可重试，刷新不丢失已保存消息。图片（3MB 内）和语音（最长 60 秒、3MB 内）只在本机保存和回放；文字模型不会读取附件。录音结束后可先预听，再发送或移除；发送后的语音支持播放、暂停和拖动进度，普通会话刷新后仍可播放。同一聊天内只播放一段语音，开始录音、移除预听、撤回消息或离开聊天会停止相应播放。播放依赖浏览器对录音格式的支持，不支持时会显示提示；不提供语音转文字、模型听写或语音通话。

本地规则会从明确的用户偏好、计划、重要话语和敏感自述中提议记忆，原话和消息来源始终保留。所有提议都需在回忆页确认，未确认内容不参与长期召回或摘要。仍支持聊天消息下“记住这条”和手动添加。支持重要度 1–5、“永远别忘”、到期和归档；过期与归档内容不召回，年龄本身不会删除重要记忆。相反的已支持事实槽（称呼、饮食及部分偏好）需再次确认后归档旧记录，不自动选定一方；恢复归档也先成为待确认提议。

回忆页可关闭某类记忆的提议、摘要和已有引用，也可关闭自动整理而只保留原始聊天。健康、创伤、性、身份等检测到的敏感自述必须确认且不进入自动摘要。规则是保守启发式，不是通用自然语言理解或完备的敏感信息分类器；未识别的敏感主题可使用临时会话。临时模式从空会话开始，不落盘、不提取或读取长期记忆，结束模式/刷新后消失；生成回复的临时文字仍会发给所配置的模型服务。

聊天搜索只筛选当前角色的原始消息正文，忽略英文大小写及关键词首尾空格；关闭搜索会恢复完整列表，撤回消息不参与搜索。引用可取消并随消息保存；文字引用会以标注的数据传入模型上下文，单条引用最多 600 字，仍受近期上下文总预算限制（超出预算时优先保留当前消息正文）。图片/语音引用只显示类型，不发送附件给文字模型。撤回会清除正文和附件、取消尚未发送的引用、停用重试，既有引用显示“引用的消息已撤回”；撤回来源及紧随其后的角色回复不再用于后续请求，但已显示的角色回复仍保留本机。过期的“记住这条”操作不能重新保存已撤回来源。回复进行中需先停止再撤回。

本地召回最多 5 条相关记忆、共 2000 字，近期上下文最多 12 条/6000 字，额外选取至多两条相关周期摘要。语义匹配使用本地中英文主题词表而非向量或外部 embedding 服务，未知主题降级文字匹配。摘要从全部可整理对话持续重建，按 UTC 日/ISO 周/月/年分层，保留所有符合条件的原始消息 ID；摘要正文为最多 1400 字的话题统计与代表性原文，不是模型生成的完整叙事。无时间戳的旧消息无法可靠分期，敏感、待确认、关闭类别、撤回和被遗忘来源及关联回复不进入摘要。

修订、暂停、归档、拒绝或删除记忆会失效摘要引用；删除/纠正来源写入本地遗忘标记，防止从保留的原始聊天重新生成或发送旧事实。撤回原消息同时归档关联记忆。原始聊天可仍保留用于本机查看；已经发给外部服务的上下文无法撤回。旧导出备份不受自动控制，请自行删除。

在“我的 → 本机聊天与记忆”设置至少 6 位密码后导出加密 JSON；换机时选择文件，输入原密码，再确认替换。旧版未加密 JSON 可留空密码。密码错误或文件无效时保留当前数据，可直接修改密码后重试同一文件；忘记密码无法恢复。操作期间会禁用本面板其他操作，结果独立于 DeepSeek 连接提示。导入/清空前请关闭其他 Aily 标签页并暂停主动消息。

备份包含聊天与附件、记忆、摘要、称呼偏好和记忆设置，不含 API Key、成年确认、演示钱包、主动消息设置及故事进度。导入在校验后事务替换现有数据；导入和清空聊天会重置主动消息设置与故事进度，钱包不变。清空需单独确认，且不是删除全部本机使用资料。清除站点数据或卸载浏览器仍可能丢失未备份记录。

```bash

node scripts/verify-data-transfer.mjs
```

## 关系回忆视图

“回忆”页保留原有记忆管理，并可切换“回忆卡”“周记月记”和“时间轴”。新视图只展示当前所选角色已确认、允许引用的共同经历；待确认、归档、到期、暂停或关闭类别的事件不进入卡片和时间轴，不把消息数量当作关系成长。时间轴按确认时间从早到晚排列（UTC），不是推断真实事件发生日期。

回忆卡展示所关联原聊天的本机图片附件；无图或图片无法读取时显示明确标注的插画，不假称实拍或模型生成图片。不新增云端上传、图片理解或分享服务。

周记／月记按 UTC ISO 周和自然月自动整理非敏感共同经历摘录，不是模型叙事。关闭自动整理后不生成草稿。先预览，再确认保存到当前主角色的长期记忆；其他角色可查看，但需在消息页切换主角色后才能保存。取消预览不写入数据，失败可重试。同一份摘录保存后不重复提供确认；源事件变化可形成新版草稿。

保存的周记／月记是独立文本快照（使用 `【周记 · 周期】` / `【月记 · 周期】` 标题），不会递归进入新草稿；可在记忆管理中编辑、暂停、归档或删除，随现有加密备份导出／导入。删除或修订原事件不会自动改写已确认快照，如需删除其中信息，请同时编辑或删除快照及旧备份。正文有摘录长度上限，完整事件可展开来源回看。

实际应用前后对比见 [关系回忆视觉证据](docs/evidence/relationship-memories/README.md)。


## 月度回忆册与隐私分享

“回忆 → 月度回忆册”按确认时间的 UTC 自然月整理当前所选角色的非敏感共同经历，可选择月份、勾选条目并预览对外分享内容。待确认、归档、暂停、到期、已撤回来源、关闭类别以及已保存周记/月记不参与；关闭自动整理后不生成回忆册。册子在本机即时构建，不新增持久存储、不改写原记忆、不调用模型。

默认只分享月份、固定 AI 角色名、数量和匿名小事条目，不含原文、用户称呼、原聊天、照片、来源编号或精确日期。主动勾选“包含脱敏文字摘录”后，隐藏常见联系方式、链接、长数字、配置的称呼和额外指定的词语，每条最多 240 字。敏感分类与文字脱敏都是保守规则，不能保证识别所有姓名、地点、隐语或隐私；必须逐条检查预览并确认后才能导出。来源、筛选或设置变化需重新预览，导出时再次检查到期。

支持浏览器原生文字分享；不支持时下载 UTF-8 `.txt` 文件，可自行发送给朋友。下载入口始终可用；取消原生分享不自动下载。没有公开网页、云端链接或上传服务。只声明已交给系统/发起下载，不声称朋友已经收到。本机修改、删除资料不能撤回已经分享的副本，请自行管理旧文件。

```bash
# 启动 npm run dev -- --host 127.0.0.1 --port 4321 --strictPort 后：
node scripts/verify-monthly-album.mjs
```

## 朋友圈动态与互动

底部“此刻”可选择三位角色，手动生成虚构动态、点赞/取消点赞、评论、重试角色回应、隐藏动态，并把动态及评论上下文带入对应角色私聊（不会自动发送）。没有 Key 时使用明确标注的本机演示文案；配置模型后，动态和评论回应复用现有 DeepSeek 连接，成功完成才保存模型输出。回应失败保留评论，可重试而不重复发表评论。

动态请求不读取聊天、长期记忆或摘要；仅提交角色生成任务、当前动态和评论，并遵守已设置的互动边界。配图为固定本机示意图，不调用图片模型。没有后台定时发布、通知、自动个性化或共同事件发布功能。

动态与互动保存在聊天 IndexedDB 的独立内部设置中，刷新、切换页面和同浏览器多标签页同步保留；最多保留最近 60 条动态，每条最多 50 条评论。动态不包含在聊天加密备份中；导入或清空全部聊天会重置动态和互动，隐藏内容也会删除其互动。清除站点数据会丢失记录。

```bash
# 在 npm run dev -- --host 127.0.0.1 --port 4193 --strictPort 启动后：
node scripts/verify-social-feed.mjs
```

## 商城充值与送礼演示

底部“商城”提供不扣款的本机体验：免费模拟充值 100/300/1000 演示币，选择三位角色之一，赠送鲜花、热饮或小夜灯（数量 1–99）。充值和送礼都需确认，可取消；余额不足不扣币、不生成送礼记录。

余额和交易记录单独保存到本机 IndexedDB，刷新后保留，同一浏览器不同标签页同步。演示币没有现金价值、不可提现，不接入应用商店或任何真实支付渠道。礼物回应是固定本地文案，不调用模型、不改变聊天、记忆或剧情权益；不送礼也不会影响基本回应。

演示钱包与聊天数据隔离，不包含在聊天加密备份中，聊天的导入/清空不重置钱包。清除浏览器站点数据会删除演示币与记录。

## 角色主动消息（本机演示）

“我的 → 角色主动消息设置”按角色开启（默认关闭），选择时间、天气或关系阶段情境、频率和免打扰时段。早间 08–11 / 傍晚 18–22 的问候、用户手动提供且 6 小时内有效的天气提示，以及有效确认回忆带来的关系阶段上升，都会以明确标注的本机文案进入角色聊天；不调用模型、不获取定位或真实天气。

轻量/适中/频繁分别最多每天 1/2/3 条，最短间隔 24/6/3 小时。每日额度及免打扰按设备本地时间，支持跨午夜；起止相同为全天免打扰。天气、关系阶段、时间按此顺序选取，受同一额度限制。最近 30 分钟发过消息、正在回复或临时会话时暂停；只有应用打开且页面可见时检查（每 30 秒及设置保存/页面重新可见时），不提供离线或系统推送，不补发过期问候。关系下降不发消息，恢复已问候过的阶段不重复问候。

消息追加和调度状态在同一 IndexedDB 事务中保存，多个标签页不会重复发送同一情境；关闭再开启不会重置频率限制。设置和调度记录不包含在聊天加密备份中，导入/清空聊天会重置；主动消息本身随聊天备份。当前原型不裁剪调度历史，长期使用会增加本机存储占用。

## 安全、AI 身份与隐私删除（原型）

首次体验及升级后的现有本机资料都需确认 18 周岁以上与 AI / 数据说明。确认独立于聊天备份，导入旧备份不能绕过；这里只是成年自我声明，不是身份核验。本原型不开放露骨色情内容。角色始终是 AI，不替代现实关系、医疗或紧急服务。

中英文保守本机规则对检测到的自伤、暴力意图及露骨色情 / 未成年人性化请求返回明确标注的本地安全回复，不调用模型；后续请求也排除检测到的高风险用户轮次、关联回复及来源关联的记忆 / 摘要，原始记录仍在本机可查看。危机提示在中国大陆提供 110（警方）/ 120（急救），其他地区建议当地紧急服务及可信任的人，不猜测用户位置或编造热线。模型上下文始终附带禁止依赖 / 付费操纵、伪装真人及专业诊断的边界。

外部服务仍使用 SSE，但现在等待完整文本完成本机检查后再显示，避免先展示被检查命中的不安全片段；停止、超时或错误不会保留未检查的部分回复。输入与回复检查限 24000 个 JS 字符单元；超限拒绝处理。输出检查、年龄声明和提示词都不是生产级审核，可能误判或漏检，不覆盖附件理解、隐语或全部风险。正式发行仍需验证内容审核、年龄核验与合规策略。

“我的 → 安全与隐私 → 删除本机使用资料”需输入“删除”确认，可取消；清除全部聊天 / 记忆 / 附件 / 摘要 / 设置、当前会话 Key、成年确认及独立演示钱包，然后退出。各应用标签页持有共享 Web Lock，删除需独占；其他标签页存在时不删除，需先关闭。删除前暂停并等待本页主动消息和整理，卸载消费者后再清除。不同数据库 / 浏览器存储无法共同事务回滚，若部分步骤失败会明确显示未完成，可重试，绝不显示成功。不支持 Web Locks 的浏览器需使用站点数据清除功能。

本机 IndexedDB 记录本身未加密，需依赖设备保护；密码加密仅用于导出备份。没有服务器账户、人工客服、举报申诉或真实扣费服务，不能将本机重置宣称为线上账户注销。删除不影响已发给外部服务的数据、下载的备份或其他设备 / 浏览器；外部模型的留存与训练政策需用户自行核查。应用未接入训练上传，不要求训练授权，也没有个性化推荐服务。

```bash
# 在 npm run dev -- --host 127.0.0.1 --port 4293 --strictPort 启动后：
node scripts/verify-safety-privacy.mjs
```

真实应用修改前 / 后截图与场景说明见 [安全隐私视觉证据](docs/evidence/safety-privacy/README.md)。

## 七天互动主线

在陆听澜聊天内点击“共同故事”，进入《把日子慢慢写成我们》：从第一顿晚饭到共同写下海边明信片，七章各含两种选择、角色回应与后续呼应，第七章回看整段经历。陈奕恒与顾辰泽仍保留原来的单篇日常故事，不冒充已有完整主线。

每个设备本地日最多确认一章，下一章在下一本地日开放；中断几天仍从下一章继续，不重置、不降级、不付费解锁。已完成章节可随时回看，但不能重选或重复生成回忆。预览和重新选择不写入数据；点击“确认保存选择与回忆”才将章节进度和关系回忆在同一 IndexedDB 事务中保存，失败可重试，多标签页以首个成功保存为准。
