# Aily

以「长期陪伴、共同经历、关系成长」为核心的 AI 亲密关系应用原型。

## 当前原型

- 三位差异化 AI 角色与主角色切换
- 液态玻璃风格的移动端消息首页
- 按角色隔离的文字聊天、DeepSeek 流式回复、停止/重试、引用、撤回和搜索
- 自动提议、用户确认的分类长期记忆：原话/来源、重要度、固定、情境到期、归档、冲突确认和纠错
- 持续更新的日/周/月/年本地话题摘要与中英文主题语义检索（未知主题使用文字匹配）
- 按角色关闭记忆类别/智能整理，以及不落盘、不读取长期记忆的临时会话
- 图片分享与语音录制/回放（仅本机保存，不提供模型视觉理解或语音听写）
- AI 角色动态、关系回忆时间轴和隐私提示
- 本地优先存储，刷新后保留体验进度

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 聊天与记忆

在“我的 → DeepSeek 连接”填写自己的 API Key。对话及少量相关确认记忆会直发配置的服务；Key 只保存在当前浏览器会话。没有 Key 时明确使用本地演示回复，不是 AI 生成内容。不要在客户端构建中预置生产密钥。

用户消息在请求前写入 IndexedDB。回复失败或停止后可重试，刷新不丢失已保存消息。图片（3MB 内）和语音（最长 60 秒、3MB 内）只在本机保存和回放；文字模型不会读取附件。

本地规则会从明确的用户偏好、计划、重要话语和敏感自述中提议记忆，原话和消息来源始终保留。所有提议都需在回忆页确认，未确认内容不参与长期召回或摘要。仍支持聊天消息下“记住这条”和手动添加。支持重要度 1–5、“永远别忘”、到期和归档；过期与归档内容不召回，年龄本身不会删除重要记忆。相反的已支持事实槽（称呼、饮食及部分偏好）需再次确认后归档旧记录，不自动选定一方；恢复归档也先成为待确认提议。

回忆页可关闭某类记忆的提议、摘要和已有引用，也可关闭自动整理而只保留原始聊天。健康、创伤、性、身份等检测到的敏感自述必须确认且不进入自动摘要。规则是保守启发式，不是通用自然语言理解或完备的敏感信息分类器；未识别的敏感主题可使用临时会话。临时模式从空会话开始，不落盘、不提取或读取长期记忆，结束模式/刷新后消失；生成回复的临时文字仍会发给所配置的模型服务。

本地召回最多 5 条相关记忆、共 2000 字，近期上下文最多 12 条/6000 字，额外选取至多两条相关周期摘要。语义匹配使用本地中英文主题词表而非向量或外部 embedding 服务，未知主题降级文字匹配。摘要从全部可整理对话持续重建，按 UTC 日/ISO 周/月/年分层，保留所有符合条件的原始消息 ID；摘要正文为最多 1400 字的话题统计与代表性原文，不是模型生成的完整叙事。无时间戳的旧消息无法可靠分期，敏感、待确认、关闭类别、撤回和被遗忘来源及关联回复不进入摘要。

修订、暂停、归档、拒绝或删除记忆会失效摘要引用；删除/纠正来源写入本地遗忘标记，防止从保留的原始聊天重新生成或发送旧事实。撤回原消息同时归档关联记忆。原始聊天可仍保留用于本机查看；已经发给外部服务的上下文无法撤回。旧导出备份不受自动控制，请自行删除。

本机数据支持密码加密导出/导入。导入替换现有数据并在写入前进行校验；忘记密码无法恢复。清除站点数据或卸载浏览器仍可能丢失未备份记录。

## 验证

```bash
npm run build
npx vitest run --pool=threads
# 在 npm run dev -- --host 127.0.0.1 --port 4175 启动后：
node scripts/verify-long-memory.mjs
```

浏览器脚本在隔离上下文中验证自动提议、确认、周期摘要、中英文语义召回、固定、冲突归档、临时会话不落盘及刷新、分类关闭持久化，不修改你的现有浏览器数据。真实 DeepSeek 服务需自带有效 Key；自动化测试使用模拟响应，不产生真实 API 费用。
