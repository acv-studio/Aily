## 范围与限制

动态为手动生成，无后台调度/通知/共同事件生成；不读取聊天或长期记忆进行个性化。图片是固定本机示意图。无 Key 时明确使用本机演示文案；配置 Key 后沿用现有连接与安全边界。最多保留最近 60 条动态、每条 50 条评论。

朋友圈数据放在聊天 IndexedDB 的独立内部设置中，跨标签页同步；不包含在聊天加密备份中，导入或清空聊天会重置，隐藏会删除该动态及其互动。私聊联动仅填写草稿，不自动发送。
