# 智能提醒合并说明

本功能已接入当前本地运行项目，而不是替换成旧的五栏导航版本。

## 当前入口

- 底部「提醒」→「智能提醒」。
- 「我的」→「陪伴与互动」→「智能提醒」。
- 有到期项时主页面/聊天页面显示横幅，可查看或延期。

保留当前的四栏导航（消息、记忆、提醒、我的）、主角色配置、桌面主页、角色朋友圈和既有主动问候设置。

## 功能与限制

喝水/吃饭支持一次或重复；天气关怀使用 6 小时内手动记录的温度；心情关怀仅根据 2 小时内主动记录的低落心情；地铁使用自行核对的预计到站时间、站点与出口；下一步是关键词规则建议，需要逐项确认后才创建提醒。

支持保存、完成、暂停/继续、10 分钟延期和确认删除，最多 500 条。默认没有提醒。重复项完成后排到下一个未来周期，不逐一补发历史周期。免打扰默认设备时间 22:00–08:00；地铁提醒不受免打扰限制。

这仍然是**本机规则版**：仅在完成引导与隐私确认、应用打开且页面可见时，约每 15 秒检查。没有实时路线/定位、自动天气、关闭应用后的系统推送或 AI 预测，不可作为可靠的实时地铁到站通知。

数据保存在当前浏览器的内部 IndexedDB 设置中，不加密、不包含在聊天备份内。导入、清空聊天数据或删除本机资料会重置提醒。删除前会停止调度并等待进行中的操作完成。

## 验证命令

```bash
npm test
npm run build
node scripts/verify-smart-reminders-live.mjs
```

浏览器验证脚本默认检查用户现有地址 `http://127.0.0.1:4175/`，通过独立浏览器上下文创建测试数据，不修改用户日常浏览器的记录、不启动替代服务器。

如果需要部署到公网或合并远端 Git 分支，需要另行执行发布流程；本次是合并到当前本地项目并验证现有本地地址。
