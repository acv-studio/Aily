# Chinese / English localization

The interface starts in English for an English browser locale and Simplified Chinese otherwise. The welcome page and **Profile → Language settings** allow an explicit interface override. Profile separately offers **Chat language**: Chinese, English or follow user input. Preferences survive refresh and synchronize between same-origin tabs without resetting IndexedDB chats, memories, relationships, wallet or character selection. If browser storage is unavailable, switches remain usable for the current page.

## Resources and content boundaries

`src/i18n.tsx` contains the shared subscription, language preferences, interpolation and translation lookup. Chinese source keys are the Simplified Chinese resource; matching English values are grouped in `src/locales/`. Keep all new static interface strings in these resources, including accessible names, notices, confirmations and privacy disclosures. Named placeholders are substituted literally, not as HTML. React continues to escape rendered text.

All current screens are localized: the nine-step onboarding and profile editor, characters, home, moments, profile, API configuration and backup controls, chat actions and attachment disclosures, memory controls, summaries, demo gifts, proactive-message settings, the seven-day Lu storyline (all chapters, both choices, callbacks and final recap), the other-character story and mini-game, safety/age/data disclosures, privacy deletion and voice-preview/playback accessibility and errors. New fixed demo replies and proactive messages use the response language. Existing conversations, comments, memories, original wording and saved gift/activity records are never rewritten as a side effect of switching languages. Dates and demo amounts use the selected interface locale.

Chat requests carry an explicit language requirement and language-specific persona instructions. Follow-user mode detects Chinese/Latin input locally; mixed input uses a bounded character/word heuristic, not a general language detector. Punctuation-only input falls back to the interface language. Provider output is streamed as returned; this does not claim to force an arbitrary external provider to obey its prompt or silently issue a second paid request.

## Cross-language memory

Confirmed facts remain in their original wording. New proposals and manually confirmed memories retain optional original-language metadata (`zh-CN`, `en`, `mixed`), plus the existing normalized topic index. Legacy backups and untagged memories continue to work with no schema migration. Backup validation allowlists the optional metadata. The local curated bilingual topic/lexical retrieval already supports Chinese↔English recall and conflict checking; it is not translation, embeddings or unrestricted semantic understanding. Unsupported topics retain lexical fallback. Pending, expired, archived, disabled and other-character memories retain their existing exclusion rules.

Summary display translates only known generated structural labels. Its original excerpts, source identifiers and stored digest stay unchanged. There is no external memory-translation API and no automatic translation or mutation of original quotes.
