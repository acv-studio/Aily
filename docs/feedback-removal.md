# 反馈应用移除

“反馈”小应用已从 Aily 移除：桌面、应用商店和应用数据目录不再展示或注册该应用；不再默认安装，也不能通过旧 ID 重新安装。反馈页面、邮件组装逻辑及专用 iOS FeedbackMail 插件已删除。

## 旧版本兼容

- `feedback` 被列为退役扩展 ID；旧安装列表仍可读取，读取时过滤该 ID，其他未知或损坏状态继续严格报错。
- 启动时仅移除安装列表和默认安装标记中的 `feedback`，保留其他应用的安装状态和业务记录。
- `aily.ext.feedback.v1` 中的历史草稿保留，不自动读取或发送，也不因功能移除而清空。
- 既有“删除本机使用资料”流程仍保留该历史数据键的清理责任，避免遗留草稿永远无法删除。
- 退役 ID 不能被其他应用或数据 Provider 重新占用；旧直接入口显示应用暂不可用。

## 验证

相关回归测试覆盖新用户不默认安装、旧安装标记迁移、草稿保留、错误回滚、商店搜索及直接入口，以及剩余应用的数据访问。移动 WebKit 使用隔离浏览器数据验证桌面、商店和刷新后均无反馈入口。
